# Newsletter issue

Structure, in this order:
1. **Hook** (2-3 sentences): a concrete situation the reader has been in.
2. **The idea in one sentence.**
3. **Intuition**: an analogy, then where the analogy breaks.
4. **Mechanism**: how it actually works, with one diagram request for the designer (`visuals/requests.md`).
5. **Worked example** with real numbers or code.
6. **So what**: what to do differently on Monday.
7. **Sources**: every link used, primary sources first.

Read it aloud: cut any sentence that does not move the reader forward. Mark anything you could not verify `(unverified)`.
