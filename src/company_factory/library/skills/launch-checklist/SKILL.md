# Launch checklist

Create `marketing/launches/<date>-<slug>/` with:

1. `brief.md`: one audience, the one problem it solves in their words, the one action we want, and how we measure it (a number and a date).
2. `message.md`: headline under 10 words, a one-paragraph description, three proof points that are true today (demo, numbers, quotes with permission), honest limitations.
3. `assets.md`: what exists and what is missing - screenshots, GIF/video, docs page, changelog entry, pricing page. Every link checked.
4. `channels.md`: one row per channel (Show HN, Product Hunt, Reddit, X, LinkedIn, newsletter, communities): audience fit, the channel's rules, draft post, best time, owner. Respect each community's self-promotion rules.
5. `runbook.md`: day-of timeline, who answers comments, likely questions with answers, rollback plan if something breaks.
6. `results.md` (afterwards): numbers vs the goal, what worked, what to change.

Nothing gets posted: publishing is an approval gate. Add one approval request per channel.
