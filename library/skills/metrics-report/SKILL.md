# Metrics report

1. For each metric in `ops/metrics.md`, record this week's value, its source (file, command, dashboard) and the date. Missing data is written as `n/a (why)`, never estimated silently.
2. Compare against the key results in `company/goals.md`: on track / at risk / off track.
3. Update `ops/budget.md`: spend this month by item vs the monthly limit. Anything that would pass the limit becomes an approval request.
4. Summarize in 5 lines: what moved, what is off track, what needs a decision.
